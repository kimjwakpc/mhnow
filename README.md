# 몬헌 나우 장비 세팅

`몬헌나우_장비세팅.html` — 더블클릭하면 브라우저에서 바로 열립니다. 설치·서버 불필요.
(구버전 `몬헌나우_딜시뮬레이터.html` 은 지우셔도 됩니다.)

## 폴더 구조

```
몬헌나우_장비세팅.html      ← 최종 결과물 (데이터 내장, 이 파일 하나면 됨)
data/
  weapons.json      공식 695 + 이벤트 38 = 733 무기
  armor.json        345 방어구 + 이벤트 14 = 359
  skills.json       134 스킬 (레벨별 수치 + 한글 설명)
  driftstones.json  표류석 색상 7종 + 색깔별 스킬 풀
  monsters.json     몬스터 67 (얼굴 아이콘 포함)
  styles.json       스타일 강화 프로필 14종 + 무기 263개 연결
  rates.json        무기 종류별 스킬 발동률
  meta.json         분류·번역
  event_armor.json  이벤트 방어구 (엑셀에서 뽑아 둔 사본)
src/
  engine.js         딜 계산 엔진
  app.js            UI
  style.css
  index.template.html
  build_data.py     공식 가이드 응답 → data/*.json
  build_events.py   나우칼 응답 → 이벤트 무기 보강 (공식에 없는 것만)
  build_nowcalc.py  나우칼 응답 → styles / rates / driftstones
  build_upcoming.py data/upcoming.json → 패치 예정 몬스터 병합
  build_mhnquest.py mhn.quest 수치로 「예정」 세트 채우기 (공식·나우칼에 없는 신규 몬스터)
  mhnquest_to_json.mjs  mhn.quest 번들(JS) → sources/mhnquest/mhnquest.json  ※ node 필요
  build.py          data + src → 단일 HTML
  make_deploy.py    단일 HTML → GitHub Pages 용 docs/ (아래 「폰에서 쓰기」)
  update.py         최신 원본 받기 → 빌드 → docs 갱신 → 변경 리포트 (아래 「데이터 최신화」)
docs/               GitHub Pages 에 올리는 배포본 (자동 생성 — 손대지 않습니다)
sources/            update.py 가 받은 최신 원본 (있으면 루트의 응답 파일보다 우선)
  mhnquest/         mhn.quest 데이터 모듈과 변환된 mhnquest.json
  upcoming.json     ← data/ 안. 패치 예정 몬스터를 손으로 적는 파일
```

재빌드 (순서 중요):
```
python3 src/build_data.py      # 공식 데이터
python3 src/build_events.py    # 이벤트 무기 보강
python3 src/build_nowcalc.py   # 스타일·발동률·표류석
python3 src/build_upcoming.py  # 패치 예정 몬스터
python3 src/build.py           # 단일 HTML
```

## mhn.quest 로 채우는 신규 세트

공식 가이드와 나우칼에 아직 없는 세트(브라키디오스 · 이소네미쿠니 아종)는
커뮤니티 DB인 [mhn.quest](https://mhn.quest/) 수치로 채웁니다. `src/build_mhnquest.py` 가 합니다.

- 등급별 공격·속성·회심, 부위별 스킬, 표류석 칸, 방어력, 무기 고유 정보(탄종·병·포격·선율·사냥벌레)까지 들어갑니다.
- 목록·슬롯·도감·툴팁에 보라색 **몬퀘** 배지가 붙습니다. 공식 수치가 아니라는 표시입니다.
- 공식 가이드에 정식으로 올라오면 `data/upcoming.json` 에서 그 몬스터를 지우면 공식 데이터로 돌아갑니다.
- mhn.quest 에도 없는 세트는 예정(0 수치, 직접 입력) 상태로 남습니다.
- 검증: 두 사이트에 다 있는 세트로 맞춰 보면 무기 수치는 21,870칸 중 145칸(0.7%)만 다르고,
  방어력은 전부 일치합니다. 방어구 스킬 차이는 대부분 mhn.quest 가 최신 패치를 아직 반영하지 않은 부분입니다.
  그래서 **공식에 있는 세트는 공식 데이터를 그대로 쓰고**, 없는 세트만 mhn.quest 로 채웁니다.

## 패치 예정 몬스터

공식·나우칼 어디에도 없는 신규 몬스터를 미리 넣어 조합만 구상할 수 있습니다.
`data/upcoming.json` 에 스킬 구성을 적고 `build_upcoming.py` 를 돌리면 됩니다.

- 무기 공격력·속성·회심은 **0** 이며, 무기를 고르면 카드에 직접 입력칸이 뜹니다.
- 방어구는 G10 · 슬롯 1 · 방어력 197 로 가정합니다 (최근 ★5 세트 기준).
- 공식 데이터에 없는 스킬은 `upcoming.json` 의 `skills` 에 적으면 자동 등록됩니다.
  수치가 미공개라 딜에는 0 으로 들어갑니다.
- 목록·슬롯·도감에 **예정** 배지가 붙습니다.
- 정식 출시 후에는 `upcoming.json` 에서 해당 몬스터를 지우고 다시 빌드하면 됩니다.
- `driftstones` 항목에 `"색": ["스킬 kind"]` 로 적으면 나우칼에 아직 없는 표류석 스킬을 끼워 넣습니다.
  지금은 비어 있습니다.
  **주의** — 나우칼의 보라색(수수께끼) 목록에는 *다른 색으로 이미 얻을 수 있는 스킬*이 일부러 빠져 있습니다.
  보라색으로도 나오지만 굳이 보라색을 쓸 이유가 없어서입니다.
  예: 특수 스킬 위력 상승은 백색에, 매진·연격은 황색에 이미 있어 보라색 목록에 없습니다. 그런 건 여기에 넣지 마세요.
- 몬스터가 아닌 세트(이벤트 방어구 등)도 같은 방법으로 넣습니다. `"weapons": []` 로 두면 방어구만 만들고,
  `id`·`name` 을 mhn.quest 의 세트 이름과 맞춰 두면 `build_mhnquest.py` 가 방어력·슬롯·스킬을 채웁니다.
  현재 들어 있는 예: **가디언 세트**(공식 가이드 미등재, 나우칼·mhn.quest 에만 있음).

## 데이터 최신화

게임 패치 후에는 이 폴더를 연결한 Claude 작업에서 이렇게 말하면 됩니다.

> 몬나사이트 최신화해줘 — 폴더에서 `python3 src/update.py` 돌리고 리포트 보여줘

`update.py` 가 하는 일:

1. 최신 원본 5개를 받아 `sources/` 에 저장합니다 (공식 3 + 나우칼 1 은 하나라도 실패하거나 형식이 바뀌면 중단하고 기존 원본을 유지, mhn.quest 는 실패해도 건너뛰고 진행).

   | 저장 이름 | 주소 |
   |---|---|
   | `weapons_full.txt` | https://monsterhunternow.com/ko/weapons |
   | `방어구페이지 응답.txt` | https://monsterhunternow.com/ko/armor |
   | `스킬페이지 응답1.txt` | https://monsterhunternow.com/ko/skills |
   | `나우칼 빌드에디터.txt` | https://mhnowcalc.com/calc/build_editor.php?lang=ko |
   | `mhnquest/mhnq_data.js`, `mhnq_lang_ko.js` | https://mhn.quest/ (첫 페이지 → `/assets/index-*.js` 안에서 주소를 찾아 받음) |

2. 빌드 단계를 순서대로 돌리고 `docs/` 까지 갱신합니다. 빌드 스크립트는 `sources/` 를 폴더 루트 파일보다 우선해서 읽습니다.
3. 이전 데이터와 비교해 **추가·삭제·변경된 무기/방어구/스킬, 스타일 강화 연결 수** 를 `업데이트_리포트.md` 로 남깁니다.

```
python3 src/update.py             # 받기 + 빌드 + 리포트
python3 src/update.py --offline   # 받지 않고 지금 원본으로 빌드 + 리포트
```

- 반영할 파일: `몬헌나우_장비세팅.html`, `data/*.json`, `sources/*`, `업데이트_리포트.md`

## 폰에서 쓰기 — GitHub Pages 배포

이 저장소 하나에 소스와 배포본이 같이 있습니다. `python3 src/make_deploy.py`
(최신화할 때 자동으로 같이 돕니다) 가 `docs/` 를 만들고, GitHub Pages 가 그 폴더를 서비스합니다.

```
docs/
  index.html             빌드 결과 + 폰용 메타 삽입본
  manifest.webmanifest   홈 화면에 추가했을 때 이름·아이콘·색
  sw.js                  서비스 워커 — 한 번 열어 두면 오프라인에서도 열립니다
  icon-192.png / icon-512.png / apple-touch-icon.png
  .nojekyll              GitHub Pages 가 파일을 건드리지 않게
```

### 처음 한 번만

저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `/docs`** 저장.
1~2분 뒤 `https://<아이디>/<저장소>` 주소로 열립니다.

무료 계정은 **공개 저장소**여야 Pages 가 켜집니다. 올라가는 건 게임 데이터와 계산기 코드뿐이고
개인 세팅은 브라우저에만 남으니 공개해도 노출될 개인 정보는 없습니다.

### 그다음부터

최신화(`python3 src/update.py`)를 하면 `docs/` 가 같이 갱신됩니다. 커밋·푸시하면 1~2분 뒤 사이트에 반영됩니다.
클라우드 세션(claude.ai/code)에서 작업하면 PC 없이도 이 과정을 전부 할 수 있습니다.

### 폰에서

- **홈 화면에 추가** 하면 주소창 없이 앱처럼 열립니다 (아이폰: 공유 → 홈 화면에 추가 / 안드로이드: 메뉴 → 앱 설치).
- 한 번 연 뒤에는 **오프라인에서도** 열립니다. 몬스터 아이콘만 인터넷이 있어야 보입니다.
- 세팅은 폰 브라우저 저장소에 남습니다. PC 와 폰은 저장소가 따로라 서로 안 보이며,
  옮기려면 **링크** 버튼(세팅이 주소에 통째로 들어갑니다)이나 **내보내기 → 불러오기** 를 쓰세요.
- 스킬 매핑을 고쳐 뒀다면 PC 에서 **수정본 내보내기** → 폰에서 **수정본 불러오기** 로 옮길 수 있습니다.
- 「저장 파일 연결」은 PC 크롬 계열에서만 됩니다. 폰에서는 내보내기/불러오기를 쓰세요.

### 알아 둘 점

- `docs/index.html` 이 약 1.9MB 라 갱신할 때마다 저장소가 그만큼 커집니다. 한 해 열두 번 갱신해도 30MB 안쪽입니다.
- 받아오는 원본(`sources/*.txt`, 13MB)은 `.gitignore` 로 빼 두었습니다. `update.py` 가 매번 다시 받습니다.
  네트워크가 막힌 환경이면 `--offline` 로 지금 `data/*.json` 만 가지고 빌드할 수 있습니다.
- 검색 엔진에 안 걸리도록 `noindex` 를 넣어 두었습니다.

## 계산 모델

```
총공  = (무기공 + 무기공 × ΣA + ΣB) × ΠF
총속  = (속성   + 속성   × ΣC + ΣD) × ΠE
계    = 총공 + 총속

  ΣA = A군 합산            ΠF = F군 곱연산 = (1+f₁)×(1+f₂)×…
  ΣC = C군 합산            ΠE = E군 곱연산 = (1+e₁)×(1+e₂)×…

총회심률 = 무기회심 + Σ(회심 스킬) + 스타일 회심

              가중치
 일반   회심≥0 ? 1-회심 : 1+회심
 회심   회심≥0 ? 회심 × (1.25 + 슈퍼회심) : 0
 흉회심 회심<0 ? |회심| × 0.3 × (1 + 흉회심) : 0
 역회심 회심<0 ? |회심| × 0.7 × 0.75 : 0

최종딜 = (일반 + 회심 + 흉회심 + 역회심) × (1 + ΣG)
모션딜 = 최종딜 × 모션값 / 100
```

**검증**: 엑셀 캐시값(공 3233 / 회심 -40% / 흉회심 Lv1 → 3192.5875)을 소수점까지 재현.
상단 `계산 검증 통과` 배지가 매 실행마다 자동 확인합니다.

### 그룹

| 그룹 | 의미 | 판별 기준 |
|---|---|---|
| A | 물리 곱연산 | "공격력이 N% 상승" |
| B | 물리 가산 | "공격력이 N 상승" |
| C | 속성 곱연산 | "속성 공격력이 N% 증가" |
| D | 속성 가산 | "속성 공격력이 N 증가", 상태이상 축적치 |
| E | 속성 최종곱 **(군 내 곱연산)** | 강룡의 얼음바람, 환수의 벼락, 명룡의 파뢰, 은작룡의 홍혈, 빙룡의 얼음 갑옷 |
| F | 물리 최종곱 **(군 내 곱연산)** | 공격 활성 |
| G | 최종 곱연산 | "주는 대미지가 N% 증가" |

| CRIT / CRIT_MULT / BRUTAL / CRIT_ELEM | 회심 계열 | |

**E · F 군은 같은 군끼리 곱해집니다.**
강룡의 얼음바람 Lv1(10%) + 빙룡의 얼음 갑옷 Lv1(10%) → `1.20` 이 아니라 `1.10 × 1.10 = 1.21`.
나머지 군(A·C·G)은 합산입니다. 곱연산 군은 `src/engine.js` 의 `MULT_GROUPS` 로 관리합니다.

### 「경지」 스킬 선행 조건

`○○·경지` 는 기초 스킬 `○○` 가 **만렙(5)** 일 때만 발동합니다.
공격이 0~4면 공격·경지는 붙어 있어도 효과가 0입니다.

```
공격 Lv4 + 공격·경지 Lv2  → +200        (경지 미발동)
공격 Lv5 + 공격·경지 Lv2  → +300 +350   (경지 발동)
```

스킬 **이름**에서 자동으로 판별합니다 — `"○○·경지"` 라는 이름을 보면 `"○○"` 를 찾아
그 만렙을 선행 조건으로 잡습니다. 새 경지 스킬이 추가돼도 코드를 고칠 필요가 없습니다.
현재 자동 인식되는 것: 공격·경지, 연격·경지, 물/번개/얼음/용속성 공격 강화·경지.

미발동 스킬은 계산 과정 패널 상단에 경고로, 집계 스킬 목록에는 흐리게 표시됩니다.

### 발동률

무기를 선택하면 그 무기 종류의 발동률이 자동으로 적용됩니다 (나우칼 기준).
`0` 인 스킬은 그 무기로는 발동 불가라는 뜻입니다.
예 — 적정 거리 위력 UP: 보우건·활만 80, 나머지 0 / 포술: 건랜스·차지액스만 / 유타·향음 강화: 해머·수렵피리만.

집계 스킬 목록이나 **스킬 매핑** 탭에서 숫자를 고치면 그 값이 우선합니다.

## 상태 이상 축적 확률

독 · 마비 · 수면 · 폭파 무기를 고르면 딜 패널의 **기댓값 공격력 밑**에 축적 확률이 뜹니다 (`engine.js` 의 `ailmentChance`).

| 항목 | 더해지는 확률 | 최대 |
|---|---|---|
| 기본 | 1/3 | — |
| 고룡 버프 — 염왕룡의 폭발가루(폭파) · 하룡의 독 안개(독) | Lv 당 1/9 | 1/3 (Lv3) |
| 추가 공격【폭파】 (폭파 무기) | Lv 당 1/15 | 1/3 (Lv5) |
| 기습【상태 이상】 (**뒤에서 공격할 때만**) | Lv 당 2/15 | 2/3 (Lv5) |

- 고룡 버프는 무기 속성이 맞을 때만 더합니다 (폭파 무기에 하룡의 독 안개는 0).
- 기습【상태 이상】이 있으면 「뒤에서 공격 시」 줄이 하나 더 나옵니다. 합계는 100% 를 넘지 않습니다.
- 아래에 어떤 스킬이 몇 % 를 더했는지 출처가 같이 표시됩니다.
- **「상태 이상 축적 시 위력 UP」 발동률이 이 확률에 연동됩니다.** 예전엔 0.33 고정이었고, 이제 평소 축적 확률을 그대로 씁니다
  (기습【상태 이상】의 「뒤에서」 몫은 빼고 봅니다). 상태 이상 무기가 아니면 축적이 없으므로 0 입니다.
  - 집계 스킬 줄에 `축적 확률 연동` 표시가 붙고, 확률 칸 아래에 `→ … 발동률 0.5778 (연동)` 이 보입니다.
  - 집계 스킬 칸에서 숫자를 고치거나 발동/미발동을 누르면 그 값이 우선합니다. **평균**을 누르거나 칸을 비우면 다시 연동됩니다.
  - 스킬 매핑 탭에서 발동률을 저장하면 연동이 풀리고, **기본값 복원**으로 다시 연동됩니다.
  - 세팅 비교 탭도 세팅마다 그 무기·스킬 기준으로 다시 계산합니다.

## 집계 스킬 — 레벨별 증가치

장비 세팅 화면에서 **방어구 → 집계 스킬 → 계산 과정** 순서로 나옵니다.
각 스킬 줄 가운데에 설명이 붙습니다.

- 설명 문장 안의 수치는 **현재 레벨 값**이 주황색 굵은 글씨로 들어갑니다.
- 그 아래 `Lv1 50 · Lv2 100 · … · Lv5 300` 처럼 레벨별 증가치가 나오고, 현재 레벨 칸이 주황색으로 칠해집니다.
  상한을 넘었으면 최대 레벨 칸이 칠해집니다.
- 수치가 아니라 말만 바뀌는 스킬(조금 → 크게 등)은 바뀌는 말만 칸으로 보여 줍니다.
  레벨마다 문장이 크게 다르면 레벨별 문장을 줄로 보여 주고 현재 레벨 줄을 굵게 표시합니다.
- 설명은 공식 가이드의 스킬 문구에서 자동으로 만듭니다 (`data/skills.json`).

## 선택 창 — 스킬 검색과 폰 화면

- **스킬 목록은 「지금 고를 수 있는 것」만** 나옵니다. 무기는 전체 145종 중 72종만 가지고 있어서
  전부 늘어놓으면 절반 이상이 눌러도 0개가 나옵니다. 옆에 그 스킬을 가진 장비 수(`용맹 · 12`)가 같이 붙습니다.
  무기 종류를 고르면 한 번 더 좁혀집니다 (대검 → 43종). 고른 스킬이 목록에서 빠지면 자동으로 해제됩니다.
- **스킬 · 이름 칸이 맨 위**에 있습니다. 아이콘 그리드에 묻히지 않게 자리를 옮겼습니다.
- 폰(가로 700px 이하)에서는 **속성 · 세트**를 접어 두고, 아이콘 그리드는 두 줄까지만 보이고 그 안에서 스크롤됩니다.
  창을 열면 검색칸과 결과가 한 화면에 들어옵니다. PC 에서는 전부 펼쳐진 채 그대로입니다.

## 무기 찾기 — 고유 정보로 거르기

무기 선택 창에서 무기 고유 정보로 거를 수 있습니다. 무기 종류를 고르면 그에 맞는 묶음이 바로 펼쳐지고,
고르지 않았으면 「탄종 · 화살 · 사냥벌레 · 선율 · 포격 · 병으로 찾기」를 눌러 펼칩니다.

| 무기 | 거를 수 있는 것 |
|---|---|
| 라이트보우건 · 헤비보우건 | 통상탄 · 관통탄 · 산탄 · 확산탄 · 참렬탄 · 철갑유탄 · 용격탄 · 독탄 · 마비탄 · 수면탄 |
| 활 | 연사화살 · 관통화살 · 확산화살 |
| 조충곤 | 비상형 · 공투형 · 가루형 / 퀵 · 스태미나 · 파워 / 절단 · 타격 |
| 수렵피리 | 선율 36종 (공격력 UP【대】 · 회심률 UP【소】 · 고주충격파 · 각종 무효 …) |
| 건랜스 | 일반형 · 방사형 · 확산형 |
| 슬래시액스 | 강격병 · 강속성병 · 멸기병 · 독병 · 마비병 · 멸룡병 |
| 차지액스 | 유탄병 · 강속성병 |

- **속성은 구분하지 않습니다.** 확산화염탄·확산수냉탄은 모두 `확산탄`, 관통빙결탄은 `관통탄`,
  빙결탄·수냉탄·멸룡탄처럼 속성만 붙은 것은 `통상탄` 으로 묶입니다. 속성으로 좁히려면 위의 **속성** 필터를 쓰세요.
- 같은 묶음 안에서 **여러 개를 고르면 하나라도 가진 무기가 전부 뜹니다** (확산탄 + 관통탄 → 둘 중 하나라도 쏘는 보우건).
  다른 묶음을 고르면 이전 선택은 비워집니다.
- **이름 검색** 칸에 `참렬탄`, `가루형` 처럼 쳐도 찾아집니다. 도감 검색도 같습니다.
- 고를 수 있는 값은 **고른 무기 종류 기준**으로 뽑습니다. 슬래시액스를 고르면 차지액스에만 있는 유탄병은 안 보입니다.
- 병 타입은 뒤에 붙는 설명을 뗍니다 — `독병 · 검 모드 속성 +571` → `독병`.
- 선율은 【대】/【소】 를 따로 둡니다. 둘 다 찾으려면 이름 검색에 `공격력 UP` 이라고 치세요.
- 분류는 이름에서 자동으로 뽑습니다(`LV1 ` 과 속성 글자를 떼어 냄). 새 탄종·선율이 추가돼도 그대로 동작합니다.
- 값이 13개 이상인 묶음(선율)은 접어 둡니다. 요약 줄에 고른 값이 보입니다.
- **세트 그리드도 고른 무기 종류를 따라갑니다.** 수렵피리를 고르면 피리가 있는 52개 세트만 남습니다(전체 81개).
  고른 세트에 그 무기가 없으면 세트 선택이 자동으로 풀립니다. 방어구 선택 창은 그대로입니다.

## 스타일 강화가 비어 있는 무기

나우칼에 아직 안 올라온 무기는 스타일 강화가 「불가능」으로 보입니다. 실제로는 가능한 경우가 있어서,
**같은 세트에 스타일이 연결된 무기가 하나라도 있으면** 같은 세트·같은 속성 무기의 프로필을 물려받습니다
(`build_nowcalc.py`). 스타일 수치는 세트·속성이 같으면 동일합니다.

- 세트 전체가 비어 있으면 그 세트는 실제로 스타일 강화가 없는 것이므로 건드리지 않습니다.
- 물려받은 무기는 스타일 강화 카드 제목 옆에 **세트 기준** 배지가 붙습니다.
- 현재 5개: 푸케푸케 건랜스 · 보로스 태도/차지액스 · 레이아 대검/라이트보우건.
  나우칼에 올라오면 자동으로 정식 값으로 바뀝니다.

## 조건부 스킬 — 발동 / 평균 / 미발동

용맹(포효 때), 추격(부위 파괴 뒤), 연격(연속 명중) 처럼 **조건이 맞아야 발동하는 스킬**은
발동률로 평균을 내서 딜을 보여 줍니다. 그런데 비교할 때는 평균이 아니라
**터졌을 때 / 안 터졌을 때** 를 따로 보고 싶을 때가 있습니다.

집계 스킬의 각 줄에 **발동 · 평균 · 미발동** 버튼이 붙습니다.

| 버튼 | 발동률 | 쓸 때 |
|---|---|---|
| 발동 | 「발동 시」 값 (기본 1) | 조건이 다 맞았을 때의 최대 딜 |
| 평균 | 기준값 (직접 고칠 수 있음) | 평소 기대치 |
| 미발동 | 0 으로 고정 | 아무것도 안 터졌을 때의 최소 딜 |

**여러 번 쌓이는 스킬**은 발동률을 횟수로 씁니다. 추가 공격【폭파】는 폭파가 터질 때마다
공격력이 `30·60·90·120·150` 씩 붙고 최대 10회까지 쌓이므로, 기본값을 **발동률 4 · 발동 시 10**
으로 넣어 두었습니다 — 평소엔 4회 기준, 발동을 누르면 최대 10회 기준으로 계산됩니다.
발동 버튼에 그 값이 같이 표시됩니다.

- 발동·미발동을 고르면 그 줄의 발동률 입력칸이 잠깁니다. **평균**을 누르면 기준값으로 돌아가고 다시 고칠 수 있습니다.
- 카드 맨 위 **전부 발동 / 전부 평균 / 전부 미발동** 으로 한 번에 바꿀 수 있습니다.
- 이 상태는 세팅과 함께 저장·공유(링크)되므로, 「최대치」와 「최소치」를 각각 저장해 두고 비교 탭에서 나란히 볼 수 있습니다.

### 어떤 스킬에 버튼이 붙나

**스킬 매핑** 탭의 「조건부」 칸에서 정합니다. 기본값은 *기준 발동률이 1이 아닌 스킬 전부*(약 43개)이며,
체크를 넣고 빼서 바꿀 수 있습니다. 바꾼 내용은 **수정본 내보내기 / 수정본 불러오기** 로 옮길 수 있어
폰에서도 같은 설정을 쓸 수 있습니다.

### 발동률을 어디서 고치나

| 고치는 곳 | 적용 범위 | 저장 |
|---|---|---|
| 장비 세팅 → 집계 스킬의 숫자칸 | 이번 세팅에만 | 세팅에 함께 저장 |
| 스킬 매핑 → 「발동률」 칸 | 늘 (기본값이 됨) | 저장 · 수정본 내보내기에 포함 |

앞에 있는 것이 이깁니다. 발동률 우선순위는
`집계 스킬 칸 → 스킬 매핑 저장값 → engine.js 기본값(상태 이상 축적 시 위력 UP 은 축적 확률 연동) → 나우칼 무기 종류별 표 → 나우칼 공통 표` 입니다.
「발동 시」 값도 스킬 매핑에서 정하고 같이 저장됩니다.

## 계산 과정 패널

장비 세팅 화면 맨 아래 **계산 과정** 카드에 모든 숫자가 그대로 나옵니다.

- 그룹별로 어떤 스킬이 얼마씩 기여했는지 (`은작룡의 홍혈 Lv3 0.25` → `(1+0.25) = ×1.25`)
- 합산 군은 `+`, 곱연산 군은 `×` 로 구분해서 표시
- 총공·총속·총회심률의 실제 대입식
- 4개 회심 분기의 가중치 계산식과 기여값
- 최종 곱연산과 모션값 적용까지

수치가 이상하면 여기서 어느 단계가 틀렸는지 바로 짚을 수 있습니다.

## 일괄 선택

방어구 카드 헤더의 두 버튼입니다.

### 방어구 일괄 선택

- 스킬 검색창에 `공` 처럼 일부만 쳐도 후보가 뜹니다. 눌러서 조건에 추가합니다.
- 스킬은 **여러 개** 걸 수 있고, 스킬끼리는 `하나라도` / `전부` 를 고릅니다.
- 세트도 **여러 개** 고를 수 있습니다.
- **스킬 조건과 세트 조건은 OR** 입니다.
  공격 스킬 + 키린 세트를 걸면 *공격을 가진 방어구* 와 *키린 방어구* 가 모두 남습니다.
- 5개 부위가 세로 열로 나란히 뜨고, 각 열에서 하나씩 고릅니다.
- 조건에 건 스킬을 **많이·높게 주는 방어구가 위로** 정렬됩니다.
- 하단에 현재 조합의 스킬 합계와 표류석 슬롯 수가 실시간으로 보입니다.
  상한을 넘으면 그 자리에서 빨갛게 뜹니다.
- 하단 스킬에 마우스를 올리면 집계 스킬과 같은 **레벨별 설명**이 팝업으로 뜹니다 (현재 레벨 칸 강조, 상한 초과 시 계산에 쓰는 레벨 표시).
- `확인` 을 눌러야 실제로 착용됩니다. 같은 방어구를 유지한 부위는 표류석도 유지됩니다.

### 표류석 일괄 장착

표류석은 어느 부위에 넣든 결과가 같으므로 개수만 맞추면 됩니다.

- 현재 방어구의 **총 슬롯 수**가 상단에 칸으로 표시되고, 그만큼만 담을 수 있습니다.
- 색깔로 거르거나 스킬을 검색해서 `＋` / `−` 로 개수를 정합니다.
- 상한을 넘으면 개수가 빨갛게 표시됩니다.
- `확인` 을 누르면 부위 슬롯에 순서대로 자동 분배됩니다.

## 무기 고유 정보

무기를 고르면 종류에 맞는 카드가 하나 더 뜹니다. 공식 가이드 응답의
`gunlanceSpec` / `chargeBladeSpec` / `switchAxeSpec` / `huntingHornSpec` / `bowSpec` /
`insectGlaiveSpec` / `bowgunSpec` 을 그대로 씁니다.

| 무기 | 표시 |
|---|---|
| 라이트·헤비보우건 | 탄종 표 — 탄 이름 · 장전수 · 반동 · 리로드 (탄 색 점 포함) |
| 활 | 화살 타입 (확산화살 Lv1~4 등) |
| 차지액스 · 슬래시액스 | 병 타입 (강격병 / 강속성병 / 유탄병 …), 슬액은 검 모드 속성 보정도 |
| 건랜스 | 포격 타입 (일반형 / 확산형 / 방사형) |
| 조충곤 | 사냥벌레 (공투형·퀵·타격 식) |
| 수렵피리 | 선율 효과 목록 |

무기 선택 목록과 도감에도 요약이 한 줄 붙습니다.

### 보우건 — 반동 경감 · 장전 속도 필요 Lv

탄종 표가 `탄종 · 장전수 · 반동 · 반동 경감 · 리로드 · 장전 속도` 로 나옵니다. 규칙은 mhn.quest 와 같습니다 (`engine.js` 의 `bowgunStep`).

- **반동 · 리로드** 칸은 지금 장비의 스킬을 적용한 값입니다. 줄어들었으면 `대 → 중` 처럼 표시됩니다.
- **반동 경감 · 장전 속도** 칸은 단계가 바뀌는 Lv 만 보여 줍니다 (예: 대 → `Lv2 중` `Lv3 소`). 이미 충족한 칸은 초록색입니다.
  `효과 없음` 은 그 스킬을 올려도 안 바뀐다는 뜻입니다.
- 표 위에 지금 스킬 Lv 와 **최대 효과** Lv(이 무기의 모든 탄이 더 줄지 않는 Lv)가 나옵니다 — 몇 Lv 를 챙길지 여기서 보면 됩니다.

| 단계 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|
| 반동 중 | 소 | 소 | 소 |
| 반동 대 | 대 | 중 | 소 |
| 반동 특대 | 특대 | 특대 | 대 |
| 반동 용격 | 용격 | 용격 | 용격 |
| 리로드 보통 | 빠름 | 빠름 | 빠름 |
| 리로드 조금 느림 | 조금 느림 | 보통 | 빠름 |
| 리로드 느림 | 느림 | 느림 | 조금 느림 |

**헤비보우건 예외** — 반동 대 / 리로드 조금 느림 에서 Lv3 이어도 확산탄 · 철갑유탄 · 관통탄, 용격탄(장전 2 이상),
산탄(장전 7 이상), 참렬탄(리로드만)은 소/빠름 이 아니라 **중/보통** 까지만 내려갑니다.
공식 데이터의 `RECOIL_LARGE_2` · `RELOAD_LARGE_2` 구분과는 정확히 일치하지 않아서, mhn.quest 규칙을 따랐습니다.

## 장비 툴팁 (마우스 오버)

이름·스킬이 길어 `…` 로 잘린 장비도 마우스를 잠깐 올리면 팝업으로 전부 보입니다.

| 위치 | 팝업 내용 |
|---|---|
| 무기 슬롯 · 무기 선택 목록 | 이름 · 종류/세트/속성 · 공격/속성/회심 · 무기 스킬(레벨별 설명) · 고유 정보 전체 · 스타일 강화 가능/불가능 (슬롯은 적용 시 수치도) |
| 방어구 슬롯 · 방어구 선택 목록 · 일괄 선택 열 | 세트·부위 · 방어/표류석 칸 · 방어구 스킬(레벨별 설명) · 장착한 표류석 |
| 그 밖의 목록 (표류석 스킬 등) | 글자가 실제로 잘린 경우에만 전체 텍스트 |

- 슬롯은 **현재 고른 등급·레벨** 기준, 선택 목록은 최대 등급 Lv5 기준입니다.
- 화면 가장자리에서는 위·옆으로 자동으로 옮겨 뜹니다.
- 클릭·스크롤·키 입력 시 바로 닫히고, 터치 기기에서는 뜨지 않습니다.

## 무기 슬롯 수치 — 무기 | 스타일 적용

무기 슬롯 오른쪽이 두 칸으로 나뉩니다.

- **무기** — 무기 자체의 공격·속성·회심 (고른 등급·레벨)
- **스타일 Lv○** — 위 수치에 현재 스타일 강화(레벨 + 고른 마일스톤)만 더한 값. 초록 `+숫자` 가 더해진 양입니다.
  스타일 표가 없는 무기는 `스타일 직접 입력` 칸에 넣은 값이 더해집니다.

스킬 효과는 들어가지 않은 값이며, 스킬까지 합친 값은 오른쪽 딜 패널의 총 공격력·총 속성입니다.

## 이름 검색 — 몬스터 이름으로도

무기 선택 · 방어구 선택 · 방어구 일괄 선택 · 도감의 이름 검색칸은 **몬스터 이름**으로도 찾습니다.
`테오테스카토르` → 카이저 세트(킹테스카블레이드 …), `리오레우스 아종` → 블루 코로나 …, `안쟈나프` → 쟈나프 세트 …

- 띄어쓰기 · 하이픈은 무시합니다 (`테오-테스카토르` = `테오 테스카토르` = `테오테스카토르`).
- 일부만 쳐도 됩니다 (`테오`, `레우스`). 장비 이름 · 세트 이름 · 탄종/선율 검색도 그대로 됩니다.
- 몬스터 이름은 `data/monsters.json` (공식 가이드) 을 씁니다. 광석·이벤트 장비처럼 몬스터가 없는 세트는 세트 이름으로 찾으세요.

## 선택 창 — 검색·필터 기억

무기 선택 · 방어구 선택 · 방어구 일괄 선택 · 표류석 일괄 장착 창은 **닫아도 검색어·필터·스크롤 위치를 기억**합니다.
바깥을 눌러 실수로 닫혀도 다시 열면 그대로입니다. (새로고침하면 초기화)

- 방어구 선택의 필터는 부위끼리 공유합니다 — 머리에서 고른 세트가 다리를 열 때도 걸려 있습니다.
- 지우려면 각 창의 **필터 전체 해제 / 조건 전체 해제** 를 누르세요.
- 일괄 선택·일괄 장착 창에서 **확인 안 한 선택이 있으면** 바깥 클릭·Esc 로는 닫히지 않습니다. `✕ 닫기` 는 취소로 닫습니다.
- 검색칸에서 드래그하다 바깥에서 손을 떼도 닫히지 않습니다.
- 일괄 선택 열에서 항목을 눌러도 스크롤이 맨 위로 튀지 않습니다.

## 세팅 저장 — 새로 저장 / 덮어쓰기

딜 패널 아래에 버튼이 두 개 있습니다.

- **세팅 저장** — 항상 새로 저장합니다. 이름을 묻는데, 세팅을 불러온 상태면 `원래 이름 2` 가 미리 채워집니다.
- **덮어쓰기** — 선택창이 뜨고, 저장된 세팅 중 하나를 골라 **지금 세팅으로 덮어씁니다.** 이름은 그대로 유지됩니다.
  - 지금 불러온 세팅이 맨 위에 미리 골라져 있어서, 고친 세팅을 다시 저장할 땐 `덮어쓰기 → 덮어쓰기` 두 번이면 됩니다.
  - 각 줄에 저장된 기댓값 → 지금 기댓값과 차이(%)가 나와서 어느 쪽이 나은지 보고 고를 수 있습니다.
  - 줄을 두 번 누르면 바로 덮어씁니다. 저장된 세팅이 없으면 버튼이 꺼져 있습니다.
- 버튼 아래에 `불러온 세팅 ○○ · 바뀐 내용 있음/없음` 이 보입니다 (비교 탭에서 불러오기 · 저장 · 덮어쓰기한 세팅).
- **세팅 비교** 탭의 각 줄에도 **덮어쓰기**(확인창 있음) · **이름**(이름만 바꾸기) · **삭제**(확인창 있음) 가 있습니다.

## 세팅 저장이 사라지는 문제

HTML 파일을 더블클릭해서 열면 주소가 `file://` 이 됩니다. 이 경우 브라우저가
저장소를 임시 취급해서 **창을 닫으면 저장한 세팅이 날아갈 수 있습니다.**

세 가지 해법이 있고, 위쪽이 더 확실합니다.

### 1. 저장 파일 연결 (가장 간편)

딜 패널 아래 **저장 파일 연결** 버튼을 누르고 파일을 하나 지정하면,
그 뒤로는 세팅을 저장·삭제할 때마다 그 파일에 자동으로 기록됩니다.
다음에 열 때는 **저장 파일 열기** 로 그 파일을 한 번 지정하면 그대로 복원되고
다시 자동 저장이 걸립니다. (Chrome·Edge 지원. Firefox 는 지원하지 않아 아래 방법을 쓰세요.)

### 2. 로컬 서버로 열기 (근본 해결)

`http://` 로 열면 브라우저 저장소가 정상적으로 유지됩니다.
이 폴더에서 아래 한 줄을 실행하고 `http://localhost:8000/몬헌나우_장비세팅.html` 로 접속하세요.

```
python -m http.server 8000
```

GitHub Pages 같은 곳에 올려도 같은 효과입니다.

### 3. 수동 백업

**내보내기** 로 JSON 을 받아두고, 다음에 **불러오기** 로 여는 방식입니다.
File System Access API 를 못 쓰는 브라우저에서는 이 방법만 가능합니다.

현재 상태는 딜 패널 아래에 항상 표시됩니다.

## 정렬

무기·방어구 세트는 **게임 출시 순서**로 정렬됩니다
(광석 → 쟈그라스 → 쿠루루 → 푸케푸케 → 보로스 → …).
공식 가이드의 `series.sortOrder` / `monsters.sortOrder` 값을 그대로 씁니다.

## 스킬 매핑 탭

각 스킬이 딜 계산에 어떻게 들어가는지 표에서 직접 고칠 수 있습니다.

- **그룹** — 딜 미반영 / A~G / 회심 계열 중 선택
- **쓸 수치** — 스킬 하나가 효과를 여러 개 가질 때 딜에 쓸 줄을 고릅니다.
  예: 앙심은 `15 → 15`(지속 초)와 `10 → 40`(공격력 %) 두 줄이 있고, 후자가 맞습니다.
- **단위** — `%` 는 값÷100 배율, `그대로` 는 숫자를 그대로 가산
- **발동률** — 실제 발동 비율 (무기를 고르면 그 무기 종류 기준값이 자동)

고친 내용은 브라우저에 저장되고, **수정본 내보내기**로 JSON을 뽑을 수 있습니다.
그 파일을 주시면 기본값에 반영합니다.

## 알려진 한계

- **모션값·육질 데이터 없음** — 어느 사이트에도 없습니다. 모션값은 직접 입력합니다.
- **스타일 강화 미연결 무기** — 263개 무기만 프로필이 연결됩니다 (나우칼 기준 스타일 강화 가능 무기 전부).
  나우칼에 없는 2개(하드본로드 · 강철궁)는 확인할 수 없어 `불가능` 으로 표시되며, 값 직접 입력으로 대체됩니다.
- **딜 미반영 스킬** — 파괴왕·KO술·반사·앙갚음, 상태이상 강화(독/마비/수면/폭파 = 축적치),
  그리고 모든 유틸·내성 스킬. 판단이 틀렸다면 스킬 매핑 탭에서 고쳐 주세요.
- **상한 초과** — 같은 스킬이 최대 레벨을 넘으면 목록에 `Lv13/5`처럼 빨간 숫자로 표시되고,
  계산에는 상한값(5)만 들어갑니다.
- **무기 중간 등급 이름** — 공식이 최소·최대 등급 이름만 제공해 규칙으로 생성했습니다.
- **헤비보우건 반동·리로드** — 공식 데이터에 번역이 없는 단계(`*_LARGE_2`)가 있습니다.
  mhn.quest 가 이 단계를 각각 `대`·`조금 느림` 과 같게 취급해서 같은 이름으로 표시합니다.
- **이벤트 무기** — 공식 가이드에 없어 나우칼에서 가져왔습니다. 나우칼은 최대 등급 Lv5 스탯만 주므로
  Lv1~4 는 공식 무기에서 뽑은 배율(공격 0.835/0.876/0.917/0.959/1, 속성 0.805/0.853/0.902/0.951/1,
  상태이상 축적치 0.961/0.971/0.981/0.990/1)로 역산했습니다. 등급도 최대치 하나만 있습니다.
  나우칼 수치가 공식보다 오래된 경우가 있어 실제 게임과 다를 수 있습니다.
